# trail-races-backend

Backend application for the Trail Races project.

The application provides an API for searching and browsing mountain running races.

## Tech Stack

- Java 21
- Spring Boot 4.1.1
- Maven
- PostgreSQL (planned)

## Requirements

To run the application locally, you need:

- Java 21

The project includes Maven Wrapper, so Maven does not need to be installed separately.

## Running locally
http://localhost:8080/api/races

### Windows

Run:

```bash
.\mvnw.cmd spring-boot:run
